# Aura Day

A personal life dashboard. Habits, tasks, goals, and a focus timer stay on this phone.

Package: `com.AuraDayMNG.AuraDay`

Remote config: [N319.json](https://api2.blwsmartware.net/N319.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product | Type |
| --- | --- |
| `au_pack_1` … `au_pack_10` | Consumable coins |
| `au_remove_ads` | Non-consumable |
| `au_pro` | Non-consumable, more than 3 habits |

Three habits are free. Aura Day does not upload a routine.
